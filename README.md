# Framemark

Previs and shot planning inside Unreal Engine. One stage holds your marks, cameras, lights and Level Sequence, with a 2D floor plan that is the same data as the shot.

- **Engine:** Unreal Engine 5.8
- **Platform:** Windows 64-bit
- **Interface languages:** English, French, Simplified Chinese

This repository holds the Framemark website and manual. It contains no plugin source code.

## What it does

- **Plan:** a 2D Planner that edits the same marks, cameras and lights as the 3D level. Export as PNG, SVG or PDF.
- **Stage and block:** marks with order, facing and role, ten ready layouts, setups and a Marks Table.
- **Shoot and light:** Set To Viewport, lens list, shot scales, character light rigs aimed at the nearest eye line.
- **Sequence:** Build Sequence makes the Level Sequence and a track per camera. Key To Mark moves an actor between marks.
- **Screenplay and Story Map:** import Fountain, Final Draft, plain text, ink and articy:draft.
- **Share and render:** stage files, USD and FBX export, six Movie Render Graph templates.
